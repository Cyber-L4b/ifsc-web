1960–1970 — Surgimento das redes de computadores


As primeiras redes de computadores começaram a ser desenvolvidas com o objetivo de permitir a comunicação e o compartilhamento de informações entre diferentes computadores. A ideia de conectar máquinas em rede foi fundamental para o desenvolvimento posterior da Internet.



1969 — ARPANET


A ARPANET foi criada nos Estados Unidos como uma rede experimental financiada pela ARPA. Ela conectava inicialmente computadores de instituições de pesquisa e é considerada um dos principais antecedentes da Internet.



1970–1980 — Desenvolvimento do TCP/IP


Foram desenvolvidos os protocolos TCP (Transmission Control Protocol) e IP (Internet Protocol), responsáveis por estabelecer regras para a comunicação e o encaminhamento de dados entre diferentes redes.



1983 — Adoção do TCP/IP


A ARPANET passou a utilizar oficialmente o conjunto de protocolos TCP/IP. Esse acontecimento foi importante para a interligação de redes diferentes e para a evolução da Internet.



1983 — DNS


Foi criado o DNS (Domain Name System) para facilitar a localização de computadores na rede. Em vez de memorizar endereços numéricos, como 192.0.2.1, os usuários poderiam utilizar nomes de domínio.



1989 — Criação da World Wide Web


O cientista britânico Tim Berners-Lee, trabalhando no CERN, propôs um sistema para facilitar o compartilhamento e a consulta de informações pela Internet. Esse projeto deu origem a World Wide Web (WWW).



1990–1991 — HTML e HTTP


Tim Berners-Lee desenvolveu tecnologias fundamentais para a Web:

  • HTML (HyperText Markup Language): linguagem utilizada para estruturar páginas Web.
  • HTTP (HyperText Transfer Protocol): protocolo utilizado para a comunicação entre clientes e servidores Web.



1990 — Primeiro servidor Web


Também foi desenvolvido o primeiro **servidor Web**, responsável por armazenar e disponibilizar documentos para serem acessados pela rede.



1990 — Primeiro navegador Web


Tim Berners-Lee criou o primeiro **navegador Web**, inicialmente chamado **WorldWideWeb**. O navegador permitia acessar documentos e seguir hiperlinks.



1990–2000 — Popularização da Web


Com o surgimento de navegadores gráficos e a expansão do acesso à Internet, a Web passou a ser utilizada por um número cada vez maior de pessoas, empresas e instituições.



Web 1.0 — Web principalmente estática


A chamada **Web 1.0** era caracterizada principalmente por páginas estáticas. O usuário normalmente acessava informações publicadas por um site, com pouca possibilidade de interação ou participação.



Web moderna — aplicações interativas


As aplicações Web modernas são muito mais interativas. Elas permitem login, comentários, edição de conteúdo, compras, mensagens, vídeos, armazenamento de dados e outras funcionalidades.
